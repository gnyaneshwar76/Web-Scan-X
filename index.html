Scanner modules

Three checks, one signature each

Every module takes discovered inputs, sends a signature payload, and reads the response for proof of the flaw. Payload in → signature out.

SQL Injection

Injects ' OR '1'='1 and variants, then flags database error signatures leaking in the response.

OWASP A03 · Injection

Cross-Site Scripting

Reflects a <script> payload and checks whether it returns unescaped and executable.

OWASP A03 · Injection

CSRF

Audits every form for a missing anti-CSRF token — the gap that lets forged requests through.

OWASP A01 · Access Control
