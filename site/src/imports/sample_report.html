web.xssA05:2025 Injection / CWE-79

What it is

Input sent to this page is echoed back into the HTML without encoding, so an attacker can craft a link that runs JavaScript in a victim's browser (session theft, actions as the user).

How to check it yourself

Request the URL with a test value like "><wsxTEST> in the parameter and view source — if it appears unescaped, it's reflected.

Evidence

Marker reflected unescaped: ...<p>results for "><wsxbab08d764a></p>...

How to fix

Context-encode all output (HTML-encode < > " ' &), prefer a framework's auto-escaping template, and add a Content-Security-Policy.

web.headersA02:2025 Security Misconfiguration

What it is

No Content-Security-Policy header. CSP is the browser's main defence against cross-site scripting and data injection.

How to check it yourself

Open the site in a browser, check the Network tab response headers for 'Content-Security-Policy'. Absent = flagged.

How to fix

Add a Content-Security-Policy header. Start strict, e.g. default-src 'self'; object-src 'none'; frame-ancestors 'none'.

References

  • https://owasp.org/www-project-secure-headers/
web.csrfCWE-352 (Cross-Site Request Forgery)

What it is

This form changes state (POST) but carries no anti-CSRF token, so another site can force a logged-in user's browser to submit it without their intent.

How to check it yourself

Inspect the form's fields: no hidden token (csrf/xsrf/authenticity) means the request can be forged from off-site.

Evidence

POST form to http://127.0.0.1:63725/login; fields: user, pass

How to fix

Add a per-session/per-request anti-CSRF token and verify it server-side; set SameSite=Lax or Strict on session cookies. Most frameworks provide this — enable it.

References

  • https://owasp.org/www-community/attacks/csrf
  • https://cwe.mitre.org/data/definitions/352.html
web.headersA02:2025 Security Misconfiguration

What it is

No X-Content-Type-Options header. The browser may MIME-sniff responses and run a file as a different, dangerous type.

How to check it yourself

Check the response headers for 'X-Content-Type-Options: nosniff'.

How to fix

Add 'X-Content-Type-Options: nosniff' to every response.

References
