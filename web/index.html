What it checks

Five checks. Every finding explained.

XSS

Finds places where your site echoes input back as code a visitor's browser would run.reflected · stored · DOM

Security headers

Checks the protective headers your server should send with every page.CSP · HSTS · X-Frame-Options

TLS / certificates

Checks your HTTPS setup for old protocols and expiring certificates.TLS 1.0 · ciphers · expiry

SQL injection

Finds inputs that can reach your database and change its queries.error-based · blind

CSRF & cookies

Checks forms for anti-forgery tokens and cookies for safe flags.tokens · SameSite · Secure

Questions

Does anything get uploaded?

No. WebScanX runs on your machine and talks only to the target you give it. There's no account, no telemetry, and reports are saved locally.

Is it legal to scan a website?

Only if you own it or have written permission to test it. WebScanX asks you to confirm this before every scan. Scanning other people's systems may be illegal.

Does it fix vulnerabilities?

No. v1 finds and explains each issue and shows you how to fix it yourself. It never changes your site.

What does it need to run?

Windows 10/11, macOS 12+, or a 64-bit Linux. Or Python 3.10+ with pip. It uses about 150 MB of memory while scanning.

Is it free?

Yes. WebScanX is open-source and free to use.
